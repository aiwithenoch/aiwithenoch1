# Camera Director

Free browser-based 3D cinematography and pose-composition studio.

## Direct joint posing

In **Pose joints** mode, grab a coloured joint handle and drag it directly. The app uses constrained inverse kinematics so wrists, elbows, ankles, knees, the head, chest and pelvis can be repositioned while connected limbs follow and keep their lengths. Hold **Shift** while dragging for a depth-oriented drag plane.

## Features

- Interactive camera, lens, orbit, elevation, distance and bird's-eye controls
- One or two articulated human mannequins
- Direct wrist, elbow, shoulder, head, chest, pelvis, hip, knee and ankle dragging
- Two-bone inverse kinematics for arms and legs
- Pose Studio with reusable presets and custom pose saving
- PNG reference, project JSON and GLB scene export
- ChatGPT image-generation handoff
- MCP endpoint at `/mcp`
